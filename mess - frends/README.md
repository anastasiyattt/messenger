# Бэкннд
1. Создание Базы данных
- get_db() Функция соединения с базой данных
- init_db() Функция создание Базы данных через контекстный менеджер и SQL запрос
* Переделать на основе SQLAlchemy (стадарт работы с базами данных)

2. Пути @app.route
- login() Совмешенная функция которая будет обслуживать вход и регистрацию
- chats() Функция для обработки чатов
- chat(username) Функция для открытия конкретного чата
- send() Функция для отправки сообщений
- logout() Функция обработки разлогинивания
* Добавление веб сокета (Прямое соединение чтобы не требовалось обновлять страничку)
* Изменение логики работы отображения чатов чтобы выгружались не все доступные а только те с кем создали диалог(Для этого понадобится 2 новых пути и дополнительные поля в базе данных)

3. if __name__ == '__main__' Точка входа в программу
